# Design System Rules

- **Palette**: Tailwind CSS v4 using programmatically scaled `oklch` variables.
- **Glassmorphism**: Use `.glass-panel` to counteract bright ambient glare in commercial kitchens.
- **Iconography**: Only Japanese Gokujo curved knife profiles.
- **Touch Targets**: Thicker borders, larger click targets, and wake-locks for active cooking modes.
